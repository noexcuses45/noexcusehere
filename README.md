# Social Scheduler

An Android app for planning social media posts once and sending them to Instagram, Facebook Pages, TikTok, YouTube and LinkedIn at the time you choose.

The app lives in [`social-scheduler/`](social-scheduler/). Start with its guide: **[social-scheduler/README.md](social-scheduler/README.md)** (what it does, installing, connecting your accounts, and how it is built).

## Getting the app

Every change to the app is built automatically by GitHub (Actions tab > *Build Social Scheduler APK*). Open the latest run and download **social-scheduler-apk** under Artifacts, or, once the signing key is set up, grab the APK from Releases.
